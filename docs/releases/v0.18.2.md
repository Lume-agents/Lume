# Lume 0.18.2

Esta versão facilita muito o primeiro uso: o Lume agora ajuda a instalar as CLIs dos agentes e guia a configuração. O chat também ganhou o medidor de contexto, o menu "+" e várias melhorias, e o chat do Terminal passou a ter as mesmas ferramentas do Workspace.

## Novidades

- **Instalação das CLIs pelo próprio Lume:** em Configurações → Agentes, cada agente é um cartão com o estado (Não instalado, Instalado ou Conectado) e um botão principal que muda conforme o passo: Instalar, Conectar ou Testar. O Lume mostra o comando exato, pede confirmação, exibe a saída ao vivo e permite cancelar. Funciona para Claude Code, Codex, Gemini, OpenCode, Antigravity e o GitHub CLI.
- **Guia de primeiro uso:** na primeira abertura, um passo a passo apresenta o Lume, ajuda a instalar e conectar os agentes e o GitHub CLI e termina com dicas. Ele aparece uma vez só e pode ser reaberto em Configurações → Agentes.
- **Medidor de contexto:** o chat do Claude Code mostra quanto do contexto da conversa está em uso, com aviso de cor perto do limite.
- **Menu "+" no chat:** o botão de anexar virou um menu com Anexar arquivo, Compactar contexto (Claude Code) e MCP.
- **Links na caixa de texto:** links digitados são destacados e abrem com Ctrl+clique (Cmd+clique no Mac). Nas mensagens enviadas, os links são clicáveis.
- **Menções `@`:** com o menu aberto, a seta para a esquerda volta uma pasta.
- **Chat do Terminal com as mesmas ferramentas do Workspace:** menções `@`, histórico de prompts com as setas, painel MCP, links, medidor de contexto e compactar.

## Melhorias e correções

- **Claude Code:** a fila de prompts e o botão de interromper agora aparecem no chat do Workspace para conversas abertas pelo Lume.
- O chat do Claude Code não "para" mais por um instante ao enviar um prompt.
- Os botões dos pedidos de permissão mostram um indicador enquanto a decisão é enviada.

## Observações

- A instalação pelo Lume usa os instaladores oficiais de cada CLI (ou npm, winget e Homebrew quando presentes). No Windows, o `winget` pode abrir um pedido de permissão de administrador. O login de cada agente continua sendo feito na própria CLI; o Lume mostra o comando.
- O botão Compactar contexto envia o comando `/compact` do Claude Code. Se ele não funcionar no seu ambiente, abra uma issue.
- O GitHub CLI no Linux só é instalado automaticamente quando há Homebrew; sem ele, o Lume mostra o link oficial.
