# Lume 0.18.15

Esta versão faz o usage do Claude Code acompanhar a tarefa enquanto ela roda, traz um botão de atualizar no Inspector, deixa o gráfico de tokens em horas, mostra no chat as marcas das sessões de outros computadores e corrige o modo Fast que subia o esforço, a sessão fantasma que aparecia ao abrir um chat do Claude e o menu do chat que saía da janela.

## Novidades

- **Usage em tempo real:** o Lume pede o usage ao processo do Claude Code que roda a tarefa, e não a um processo novo, então os medidores se movem enquanto ela gasta o limite. Enquanto a sessão executa, o Inspector lê o usage de novo a cada 15 s no Claude Code e a cada 30 s no Antigravity, só com a janela visível. O Codex avisa as mudanças sozinho.
- **Atualizar no Inspector:** um botão no cabeçalho lê de novo o usage e os servidores MCP da sessão, que antes eram lidos uma vez só.
- **Gráfico de tokens:** as janelas do gráfico de linha são 1 h, 5 h, 12 h e tudo, e o eixo de tempo é em horas, menos na janela de 1 h.
- **Métricas:** a seção do Inspector deixou de ter o card "Modelo". O modelo de cada prompt continua no tooltip do gráfico.
- **Indicador de trabalho:** o indicador de que o agente está trabalhando desliza e some suavemente, em vez de aparecer e sumir de uma vez.
- **Lume Remote:** as marcas de uma sessão de outro computador (compactação, interrupção, conexão perdida e troca de modelo) aparecem no chat dela, e um prompt enviado por outro computador aparece identificado como enviado do PC remoto no chat do computador que roda a sessão.

## Correções

- **Modo Fast:** ligar o Fast num chat do Claude Code que não está num modelo Opus move o chat para um Opus, e o esforço passou a ser mantido em vez de subir para o padrão do modelo novo (high).
- **Sessão fantasma:** ao abrir um chat do Claude Code, o `claude mcp list` que o Lume roda para ler a saúde dos servidores aparecia por alguns segundos como uma segunda sessão, com o nome da pasta e origem CLI. Os subcomandos do Claude que executam e saem (`mcp`, `auth`, `plugin`, `config`, `doctor`, `update`, `install`, `setup-token`) deixaram de contar como sessão.
- **Menu do chat:** o menu do botão direito no espaço vazio do chat, e o da linha de workflow, ficam dentro da janela, também quando a janela é baixa.
- **Resposta repetida:** uma resposta já escrita não é escrita de novo ao mandar o próximo prompt.
- **Tokens por prompt:** a entrada de um prompt passa a ser o que era novo para o modelo, com as releituras de cache separadas, em vez de somadas por requisição.
