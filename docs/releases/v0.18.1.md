# Lume 0.18.1

Esta versão é focada em correções, principalmente para quem usa o Lume no Windows.

## Melhorias e correções

- **Windows:** a barra de rolagem customizada do Lume agora aparece também no Windows, e arrastar agentes na barra lateral do Workspace voltou a funcionar.
- **Windows:** mandar um prompt para o Claude Code não cria mais agentes extras que sumiam depois de um tempo.
- **Ajustes:** mudar fonte, cor ou outra aparência não falha mais com "The system cannot find the file specified" quando o Lume nunca foi registrado para iniciar com o sistema.
- **Commit pelo Lume:** o botão de commit na aba Mudanças funciona de novo e mostra mensagens claras quando o Git não está configurado, não há nada para commitar ou um hook rejeita o commit.
- **Central de revisão:** o mesmo arquivo não aparece mais duplicado quando o caminho muda só na caixa das letras no Windows.
- **Prompts:** a lista de navegar prompts não mostra mais o mesmo prompt duas vezes.
- **Avisos de uso:** o aviso de limite de uso não volta nem toca de novo depois de dispensado.
- **Board:** os cards só reagem à atividade dos agentes enquanto um workflow está rodando.
- **Tarefas:** listas de marcadores em respostas comuns não viram mais tarefas no widget de to-do.
