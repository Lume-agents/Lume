# Lume 0.18.0

Esta versão deixa o `lume node` muito mais agradável de usar no terminal, traz um instalador do Windows com a cara do Lume e inclui prévias de PRs e issues do GitHub no chat.

## Novidades

- **Terminal do Node mais amigável:** rodar `lume node` sem comando abre um menu interativo com o dinossauro do Lume. Os comandos passam a mostrar uma saída legível, em português quando o sistema está nesse idioma. Para scripts, `--json` mantém a saída completa em JSON, e `--qr` mostra o código de pareamento no terminal.
- **Instalador do Windows com a identidade do Lume:** imagens e textos próprios, e o comando `lume` passa a ser registrado no PATH durante a instalação (e removido ao desinstalar), então funciona em qualquer terminal novo.
- **Prévia de PRs e issues do GitHub no chat:** ao mencionar um PR ou uma issue, o Lume mostra uma prévia dela, e a aba Mudanças permite fazer commit só dos arquivos escolhidos.

## Melhorias e correções

- No Windows, os comandos `lume node` agora mostram sua saída no terminal que os chamou.
- Duplo clique no cabeçalho do Workspace maximiza a janela no Windows, e o do Orb passa a ser reconhecido também no WebView2.

## Observações

- O instalador do Windows e o comando `lume` no PATH são novos nesta versão; se algo não funcionar no seu sistema, abra uma issue.
