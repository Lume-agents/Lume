# Lume 0.18.18

Esta versão corrige as sessões extras que apareciam no Windows a cada prompt e traz mais clareza visual para erros, compactação, workflows e ambientes.

## Novidades

- **Compactando contexto:** enquanto um `/compact` roda, o rótulo do chat diz "Compactando contexto…" e ganha um brilho âmbar com as letras se comprimindo, diferente do "Pensando…".
- **Banners de erro:** o banner entra deslizando, mostra a mensagem inteira, encolhe para uma linha depois de alguns segundos e sai deslizando para a esquerda mais tarde. Passar o mouse ou focar o banner o expande e o mantém na tela.
- **Workflow:** um balão acima de cada card mostra a última fala do agente.
- **Ambientes:** ambientes parados e shells concluídos podem ser dispensados um a um ou todos de uma vez, com **Limpar parados**.
- **Ícones:** os botões do cartão de cada agente nos Ajustes usam uma tomada para Desconectar e um frasco de laboratório para Testar. No Inspector, MCP usa um servidor e Notas usa um marcador.

## Correções

- **Windows, sessões extras:** cada prompt enviado podia listar uma nova sessão "Claude Code" do mesmo projeto. O processo que o Lume abre para o prompt, quando executado pelo `cli.js` da instalação via npm, agora é reconhecido e deixa de aparecer como sessão.
- **Testes:** o teste do gravador bloqueado do Codex aceita até três segundos, para não falhar em máquinas carregadas.
